# 更新日志

> 从第一版到现在的每一次改动，都在这里。

## 版本策略

> **语义化版本**：修 bug 升补丁位，加功能升次版本，破坏性改动升主版本。每次发版同步更新 README、llms.txt 和这个页面。

## v1.7.3 — 2026.11.12

**空收藏时点「复制清单」，提示不再露出内部键名。**

- 空列表复制改用已有的 `empty.favorites` 文案。
- 发版脚本对 jsDelivr 连刷两次，避免第一次 purge 后边缘节点仍返回上一版索引。

## v1.7.2 — 2026.11.12

**面板里可以直接把这份市场加进「发现」，收藏也可以复制成一份清单。**

- 面板底部新增「加入『发现』索引」按钮：只在 `pluginMarket` 服务可用且尚未添加时出现，点击后把本市场的 format-1 索引加进 插件 → 发现 → 索引源。
- 新增 `GET/POST /featured-market/source`，状态查询与显式添加；你之后在「发现」里删除该源，不会被自动加回。
- 收藏页新增「复制清单」：把收藏导出成 Markdown，每条带一句描述和安装命令，末尾附索引地址。
- README 补充「在 DSH 里直接用」与官方校验器说明：每次发版用 `@deepseek-ai/dsh-plugin-market-index` 的 `parseMarketIndex` 校验，坏条目会让构建失败。
- 向 `dsh-find-plugin` 提交了可选索引源的建议（issue #40）。

## v1.7.1 — 2026.11.12

**公开目录页的数字不再写死，搜索链接会直接落到结果。**

- 首屏文案里的「2,147 条」改成运行时真实收录数，数据没到时不显示数字。
- 带 `?q=` 的链接（索引条目的 homepage）打开后自动滚到结果区。

## v1.7.0 — 2026.11.12

**这个市场开始对外提供索引，别人可以拿它当数据源。**

- 发版时额外产出一份 format-1 `docs/index.json`：全部通过校验的 `dsh.bundle` 包、中英双语描述、分类、仓库、最新版本与 engines。
- 新增 `npm run build:index`，npm 元数据缓存 12 小时并限速，避免 registry 429。
- 发版流水线在重建目录后重建索引；`npm run check` 会在索引缺失、格式不对或少于 500 个插件时失败。
- README 首屏改成「安装 → 差异化 → 与 dsh-market 对比 → 索引接入」，采用数据移出首屏标题。

## v1.6.8 — 2026.11.12

## v1.6.7 — 2026.11.09

**发版时自动重建静态页，自动核对 README。**

- 一条命令发版：先重建三个静态页，再重建公开目录，最后核对文档是否同步。
- 文档检查新增三项：README 版本行与徽章、CHANGELOG 条目、本页是否有对应版本；任何一项没跟上，发版直接失败。
- 从此不需要有人记得「更新完别忘了改 README」。

## v1.6.5 — 2026.11.09

**修掉了一个会让整个面板消失的 bug，并给技能找到了入口。**

### 修复

- 点「已安装」会闪退。根因是部分插件包的语言化标题是 `{en, zh}` 对象，React 拒绝把它当子节点渲染，错误边界为了自保把整个面板卸载了。现在 Host 统一把标题规整成字符串，客户端也加了兜底，任何对象标题都不会再进渲染树。

### 新增

- **技能页**。只读列出本机全部技能（`~/.workbuddy/skills`、`~/.dsh/skills`、`~/.claude/skills`），显示每个技能做什么、什么时候触发、存在哪，并给出一句可以直接复制说给 Agent 的话。回答了那个被问了很多次的问题：技能装好了，入口在哪。
- 新接口 `GET /featured-market/skills`。
