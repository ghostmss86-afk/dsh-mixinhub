# 更新日志

> 从第一版到现在的每一次改动，都在这里。

## 版本策略

> **语义化版本**：修 bug 升补丁位，加功能升次版本，破坏性改动升主版本。每次发版同步更新 README、llms.txt 和这个页面。

## v1.6.7 — 2026.11.09

**发版时自动重建静态页，自动核对 README。**

- 一条命令发版：先重建三个静态页，再重建公开目录，最后核对文档是否同步。
- 文档检查新增三项：README 版本行与徽章、CHANGELOG 条目、本页是否有对应版本；任何一项没跟上，发版直接失败。
- 从此不需要有人记得「更新完别忘了改 README」。

## v1.6.6 — 2026.11.09

**三个新页面：关于、使用指南、更新日志。**

- 公开目录页新增「关于 / 使用指南 / 更新日志」三个入口，顶栏和页脚都能进。
- 《关于》讲清楚它为什么存在、怎么筛插件、热度怎么算、和同类有什么不同。
- 《使用指南》从安装讲到对比，六个标签页逐个说明，附三分钟速查。
- 《更新日志》收录 1.0.0 至今的每一个版本，中文重写，按版本编排。

## v1.6.5 — 2026.11.09

**修掉了一个会让整个面板消失的 bug，并给技能找到了入口。**

### 修复

- 点「已安装」会闪退。根因是部分插件包的语言化标题是 `{en, zh}` 对象，React 拒绝把它当子节点渲染，错误边界为了自保把整个面板卸载了。现在 Host 统一把标题规整成字符串，客户端也加了兜底，任何对象标题都不会再进渲染树。

### 新增

- **技能页**。只读列出本机全部技能（`~/.workbuddy/skills`、`~/.dsh/skills`、`~/.claude/skills`），显示每个技能做什么、什么时候触发、存在哪，并给出一句可以直接复制说给 Agent 的话。回答了那个被问了很多次的问题：技能装好了，入口在哪。
- 新接口 `GET /featured-market/skills`。

## v1.6.4 — 2026.11.08

**公开页有了和面板一样的海报首屏。**

- 公开目录页顶部换成会轮播的编辑精选海报，用当前插件的主色做渐变背景，下面跟四张同色系分类卡。
- 中英双语标签、移动端布局、暗色模式一并处理。

## v1.6.3 — 2026.11.08

**把面板放回宿主弹窗下面。**

- 全屏警告类弹窗（例如插件自带的用户须知）应该盖在市场之上。上一版为了穿透遮罩把层级调得过高，会把这类提示压住，这一版调回来了。
- 商店入口本身仍然能穿过遮罩被点到。

## v1.6.2 — 2026.11.08

**中文补齐，公开页对上版本号。**

- 公开目录页显示的版本号改为读取当前安装的插件版本，不再写死。
- 商店按钮可以穿过宿主弹窗的遮罩正常打开。
