# 精选插件市场

> 大多数插件市场在比谁收录得多。这个市场只回答一个问题：**我现在该装哪个。**

## 它是什么

一块放在 DeepSeek Harness 左下角的小面板。打开它，先看到的是当天的编辑精选，再往下是热度榜、项目看板、收藏、已安装和技能。每一款插件都有中英文说明，写清楚它能做什么、怎么用、要什么版本，以及一条可以直接复制的安装命令。

它不试图变成一个软件管家。它只负责把「九千多条目录」压缩成「今天值得你看的十几个」，然后把决定权交回给你。

## 为什么还要再做一个市场

插件目录已经有九千多条。搜名字能找到东西，前提是你已经知道要搜什么。

真正难的是另一种时刻：你知道自己有个问题，但不知道这个问题该由哪款插件解决。这时候，一个按下载量排序的榜单帮不上忙——它只会把已经装过的人再推一遍。

> **入选门槛**：星标不少于 25 或月下载不少于 1,200，说明不少于 24 个字符，必须是可安装的 DSH 插件包。满足门槛的两千一百多款，才进入检索范围。

## 怎么筛

1. **算分**。每一款插件按下载、星标、新鲜度三项加权，得到一个热度分。分数每天重算一次。
2. **分类限额**。编辑精选每个分类最多两款。避免榜单被同一类插件占满。
3. **人工校对**。入选条目的中英文说明会经过润色，而不是机器翻译直接上线。

## 热度不是黑箱

热度不是随机数，也不是单纯的下载排行。它是三个可解释的部分相加：

```chart
title: 热度分的构成
unit: %
max: 60
highlight: 下载
note: 新鲜度按 240 天线性衰减
source: 精选插件市场
下载 | 52
星标 | 33
新鲜度 | 15
```

- **下载占 52%**，取对数。装的人多是硬信号，但不让头部插件无限拉开。
- **星标占 33%**，同样取对数。愿意点星的人，比愿意下载的人更挑剔。
- **新鲜度占 15%**，240 天线性衰减。老插件不会因为历史存量永远压着新插件。

详情页的「？」按钮会直接摊开这三项，标出这款插件在每一项上拿了几分。看不懂的排名，就不值得信任。

## 装之前先看清楚

| 你看到的 | 它意味着什么 |
|---|---|
| 兼容当前版本 | 作者声明的版本范围包含你正在运行的 DSH |
| 要求 DSH ≥ X | 你的版本低于作者要求的最低版本，装上也跑不起来 |
| 与当前版本不兼容 | 作者写了明确上限，而你超出了这个上限 |
| 作者未声明版本范围 | 作者没写 `engines.dsh`，无法判断，不是「不兼容」 |
| 不是 DSH 插件包 | 这个包没有声明 `dsh.bundle`，不能作为插件安装 |

最后一行尤其重要。很多市场把「无法判断」直接标成绿色通过，把风险推到安装之后。这里宁可显示灰色。

## 装完之后

已安装页会列出你装过的全部插件，包括市场没收录的那些。可以启停、检查更新、一键更新、卸载。卸载是两段式确认，因为它是这一屏里唯一不可逆的操作。

收藏页和备注都存在浏览器本地。你可以把整份清单导出成一个 JSON 文件，换一台电脑再导入回来，收藏和备注都在。

## 和同类有什么不同

|  | 精选插件市场 | 大型管理器 | 选购顾问类 |
|---|---|---|---|
| 主要问题 | 我现在该装哪个 | 我装了什么、怎么管 | 帮我挑一个 |
| 决策辅助 | 并排对比 2–3 款、九项指标 | 以列表和管理为主 | 以推荐话术为主 |
| 兼容性 | 给出方向性建议，区分「不兼容」和「没声明」 | 有依赖检查 | 多数不涉及 |
| 中文说明 | 全部条目 | 部分 | 部分 |
| 技能入口 | 有，只读列出本机技能 | 无 | 无 |
| 安装包体积 | 约 0.4 MB | 数 MB | 较小 |

它不跟谁比功能数量。它比的是从「打开」到「知道装什么」要几秒。

## 它不做什么

- 不做云同步。清单和备注只在你自己的浏览器里。
- 不收集使用数据。没有账号，没有埋点上报。
- 不接管你的环境。安装、更新、卸载全部走 DSH 自己的插件管理器。
- 不承诺「精选」等于「必装」。它只是把信息摊开，决定权在你。

## 常见问题

**每天什么时候更新？** 本地时间凌晨四点。打开面板时如果发现数据过期，也会在后台补一次。

**为什么有的插件显示「不在本市场中」？** 它可能没达到入选门槛，也可能是本地开发的插件。已安装页依然会管理它。

**技能是什么？为什么没有按钮？** 技能不是插件。装好之后不会多一个图标，而是变成 Agent 的一项能力。面板里的「技能」页会把它们列出来，并给出可以直接说给 Agent 的话。

**数据存在哪？** 快照在 `~/.dsh/featured-market/`，收藏和备注在浏览器的 localStorage。删掉快照不会影响已安装的插件。

## 一句话记住它

**三十秒知道装什么，装完知道怎么用，下次还知道去哪找。**
