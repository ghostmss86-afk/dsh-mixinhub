# 使用指南

**先学会怎么选，再学会怎么用。**

## 安装

三种方式，选一种。

```bash
# npm（推荐）
dsh plugin add dsh-featured-market

# GitHub
dsh plugin add github:ghostmss86-afk/dsh-featured-market
```

也可以在本机的插件市场里搜 `dsh-featured-market`，或者在官方目录 `awesome-dsh-plugin.com` 的 market 分类里找到它。装完重启一次 DSH，左下角会出现一个商店图标。

## 打开

点左下角的商店图标。面板从底部升起，占屏幕中间，背景会变暗。

如果点了没反应，先看看是不是有别的弹窗盖在上面——首次安装时常见的是插件自带的用户须知，勾选并继续之后就能正常点开。这个插件对这类全屏遮罩做了专门的穿透处理，正常情况下不需要你先关掉它们。

## 六个标签页

1. **精选**。当天的编辑推荐，顶部是一张会轮播的海报卡，用当前推荐插件的主色做背景。往下是四张分类精选。
2. **热度榜**。按热度分排序的前三十名，带七日变化。涨得快的会标出来。
3. **项目看板**。盯你自己仓库的 star、下载、issue 和用户反馈，最多十二个项目。
4. **收藏**。你点过星的插件，可以写备注、导出清单、导入清单。
5. **已安装**。本机装了的全部插件，包括市场没收录的。可启停、检查更新、更新、卸载。
6. **技能**。本机装好的技能列表，只读。告诉你每个技能做什么、什么时候触发、可以怎么说。

## 选一款插件的四步

1. **看精选**。如果没有明确目标，直接从当天精选开始。每张卡都写了它能做什么、怎么用。
2. **搜关键词**。知道自己要什么就直接搜，中英文都行，会同时匹配名称、作者和说明。
3. **比一比**。最多挑三款，点底部的「开始对比」。九项指标并排：热度、下载、星标、分类、兼容性、包大小、收录时间、说明、安装命令。
4. **看兼容性**。详情页的「兼容性与来源」会告诉你作者要求的 DSH 版本、当前版本、包大小和代码仓库。绿色才是真的兼容，灰色是作者没声明——那不是不兼容，只是无法判断。

## 对比怎么用

在任意卡片右下角点「对比」，卡片会加上选中标记。底部会出现一条对比栏，最多放三款。点「开始对比」，进入表格视图。

每一列是一款插件，每一行是一项指标。兼容性那一行会直接给出建议，比如「要求 DSH ≥ 0.2.0，当前 0.2.2，兼容」或者「作者未声明版本范围，安装前请自行确认」。

对比完可以直接在表格底部点「获取」，不用退回详情页。

## 备注与清单

在详情页的「我的备注」里写点什么，失焦即保存。最多五百字，只存在你自己的浏览器里。

收藏页顶部有「导出清单」和「导入清单」。导出的是一个 JSON 文件，包含收藏、备注、语言和导出时间。换电脑时导入回去，收藏会自动去重合并。

## 让 Agent 帮你找

这个插件注册了一个 Agent 工具 `featured_market_search`。你不需要记命令，直接说：

> 帮我找几个做记忆管理的插件

Agent 会调用它，从两千多条索引里按热度返回结果，每条带中文说明和安装命令。它不会替你安装——会先问你。

## 技能页是什么

技能不是插件。装好一个技能，不会多一个按钮，也不会出现在侧栏。它变成 Agent 的一项能力。

「技能」页把所有本机技能列出来：做什么、什么时候触发、存在哪个目录。展开一张卡，会看到一句「可以直接这样说」的话，点复制，回到对话里说出来就行。Agent 会自己判断该不该加载这个技能。

这一页是只读的，不会改动或删除任何技能文件。

## 一些细节

- 数据每天本地时间 **04:00** 重算一次。打开面板时如果发现过期，会在后台补一次。
- 面板支持中英文切换，选择记在浏览器里。
- 收藏、备注、语言三个偏好都存在 localStorage，清浏览器数据会丢，导出的清单不会。
- 快照存在 `~/.dsh/featured-market/snapshot.json`。删掉它只会触发一次重新拉取，不影响已安装的插件。

## 常见问题

**为什么搜不到某个插件？** 它可能没达到入选门槛（星标 25 或月下载 1,200），也可能还没被目录收录。已安装页依然会管理它。

**「不在本市场中」是什么意思？** 这款插件装在你机器上，但不在当前索引里。常见于本地开发中的插件。

**更新失败怎么办？** 先在「已安装」里点「检查更新」看有没有新版本，再点「更新」。仍然失败的话，多半是网络或 registry 问题，可以稍后重试。

**卸载会删我的配置吗？** 插件自身的配置目录通常保留。这个市场只调用 DSH 的卸载接口，不会额外删除任何东西。
