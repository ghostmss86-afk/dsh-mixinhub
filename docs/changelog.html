✦✦✦02✦✦✦

v1.8.0 — 2026.11.12

所有接口先过宿主自己的准入检查。

  • 读接口和写接口都先调用宿主的 connection.requestRejection：宿主会拒绝的请求，

根本到不了市场代码，直接拿到宿主的 401/403。此前这些接口绕过了宿主的浏览器登录，

在代理或隧道后面等于把安装/卸载能力暴露给任何能连上端口的人。

  • 宿主没有发布该检查时按拒绝处理（503），而不是当作放行。
  • 写接口原有的同源写令牌保留，作为第二道闸。

v1.7.2 — 2026.11.12

面板里可以直接把这份市场加进「发现」，收藏也可以复制成一份清单。

  • 面板底部新增「加入『发现』索引」按钮：只在 pluginMarket 服务可用且尚未添加时出现，点击后把本市场的 format-1 索引加进 插件 → 发现 → 索引源。
  • 新增 GET/POST /featured-market/source，状态查询与显式添加；你之后在「发现」里删除该源，不会被自动加回。
  • 收藏页新增「复制清单」：把收藏导出成 Markdown，每条带一句描述和安装命令，末尾附索引地址。
  • README 补充「在 DSH 里直接用」与官方校验器说明：每次发版用 @deepseek-ai/dsh-plugin-market-index 的 parseMarketIndex 校验，坏条目会让构建失败。
  • 向 dsh-find-plugin 提交了可选索引源的建议（issue #40）。

v1.6.5 — 2026.11.09

修掉了一个会让整个面板消失的 bug，并给技能找到了入口。

修复

  • 点「已安装」会闪退。根因是部分插件包的语言化标题是 {en, zh} 对象，React 拒绝把它当子节点渲染，错误边界为了自保把整个面板卸载了。现在 Host 统一把标题规整成字符串，客户端也加了兜底，任何对象标题都不会再进渲染树。

新增

  • 技能页。只读列出本机全部技能（~/.workbuddy/skills、~/.dsh/skills、~/.claude/skills），显示每个技能做什么、什么时候触发、存在哪，并给出一句可以直接复制说给 Agent 的话。回答了那个被问了很多次的问题：技能装好了，入口在哪。
  • 新接口 GET /featured-market/skills。
